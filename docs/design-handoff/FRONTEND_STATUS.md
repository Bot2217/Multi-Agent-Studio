# Статус нового окна Улей

Визуальная сдача проходит через Storybook. Истории «Улей / Студия» показывают
все шесть разделов, а «Улей / События запуска» — обработку кадров контракта v1.
«Улей / Фаза 2 · Концепции» содержит отдельные прототипы команд, папки знаний,
доски, вложенных шагов и Pro.

| Этап | Материалы фронтенда | Что требуется для рабочего окна |
| --- | --- | --- |
| 0. Основа | Темы, компоненты, локали и снимки | Ревью |
| 1. Оболочка | Навигация, онбординг и диалог обновления | Передача параметров сессии и событий обновления из Tauri |
| 2. Запуск | Режимы, проверка ввода, роли, журнал, остановка, история сессии и отчёт | Подключение маршрутов v1 к живому движку, проверка доступности провайдеров и папки |
| 3. Локальные модели | Среда Ollama, фильтр тегов, ограничения, передача, подтверждение удаления и журнал | Маршруты установки и запуска среды, её происхождение и состояние, удаление, доступные ресурсы и журнал; статус загрузок и каталог уже есть в API |
| 4. Остальные разделы | Редактор ролей, каталог, просмотр файлов и настройки | Сохранение ролей и настроек, чтение папки и файлов, безопасное сохранение ключей и SSH |
| 5. MCP | Карточка и состояния в настройках | Утверждённый интерфейс чтения и управления конфигурацией MCP |
| 6. Доступность | Клавиатурная навигация и проверка axe на четырёх темах | Прогон на подключённом окне Tauri и ручное ревью |
| 7. Фаза 2 | Концепции в отдельной группе Storybook | Продуктовые решения, контракты и условия Pro |

В превью команды, загрузки, SSH, обновление и файловые операции работают на
демонстрационных данных. Настройки относятся к сессии превью. Код нового окна
не подключён к установленному приложению.

## Перед включением нового окна

Tauri должен предоставить фронтенду доверенный адрес FastAPI и сессионный
токен без передачи в URL. Действующие API задач, событий и локальных моделей
можно подключить через этот интерфейс. Форматы для недостающих маршрутов
согласует владелец движка Bot2217. URL, ключи и секреты из окружения пользователя
отсутствуют в фикстурах.

Предложение для MCP в плане остаётся макетом: идентификатор, отображаемое имя,
адрес, состояние, сообщение об ошибке и список имён инструментов. Пример
демонстрационного сервера использует адрес loopback и не отправляет запросы.
