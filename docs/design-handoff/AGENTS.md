# Системный промпт для агентов Тимохи

Этот файл — готовые правила. Его можно вставить в системный промпт агента или скопировать в `.cursor/rules` того репозитория, где агент верстает новое окно «Улья». Пока новый фронт живёт в этом репозитории, правила действуют как есть: агент читает их до первой правки.

План работ, экраны и чек-лист ревью: [PLAN_TIMOKHA.md](PLAN_TIMOKHA.md).

## Граница работы

Новое окно — это веб-фронт внутри Tauri 2: каталог `desktop/`. Сейчас там Vite и TypeScript, `desktop/src/main.ts` пустой, а пользователю показывается Streamlit. Ты строишь интерфейс, который говорит с локальным FastAPI на `127.0.0.1`. Контракт событий — версия 1.

Не трогай Python, `api/`, `core/`, `contracts/`, `locales/` как источник истины бэкенда, сборку установщика и безопасность. Эти файлы параллельно правит другой контур. Если экрану не хватает поля, опиши поле в pull request и остановись. Не расширяй контракт сам.

Не удаляй Streamlit в том же изменении, где появляется первый макет. Пока Bot2217 не переключил окно, `app.py` остаётся рабочим продуктом.

Не коммить `.env`, ключи подписи, веса моделей и скриншоты с чужими путями, где виден домашний каталог пользователя.

## Стек

React + TypeScript + Vite + Tailwind + shadcn/ui поверх Radix. Обоснование — в плане. Компоненты shadcn копируются в репозиторий и перекрашиваются под токены «Улья». Цвета по умолчанию из shadcn (zinc, нейтральный акцент) в продукт не попадают.

Иконки: Lucide, 24 px, толщина 2, `currentColor`. Для пунктов меню, которые уже нарисованы в `core/icons.py`, повтори тот же контур, чтобы два окна не разъехались. Эмодзи и растровые иконки не добавляй. Логотип — четыре соты из сайдбара, его не заменяй чужой пчелой.

Движение: Framer Motion, 160 ms, `cubic-bezier(0.2, 0.8, 0.2, 1)`, нажатие кнопки до 0.98. При `prefers-reduced-motion` не двигай layout и не масштабируй.

Типы кадров генерируй из JSON Schema и коммить:

```bash
npx --yes json-schema-to-typescript docs/contracts/ulei-contract-v1.schema.json -o desktop/src/contract/ulei-contract-v1.d.ts
```

Файл не правь руками. Неизвестный `type` и кадр с `version`, отличной от `"1"`, клиент пропускает и не падает.

## Как должен ощущаться продукт

Максимально красиво, свежо и спокойно. Это инструмент, в котором человек ставит задачу рою и видит, кто сейчас работает. Плотность как у Linear, скорость списков как у Raycast, честность шагов как у Cursor, локальные модели как у LM Studio и Jan. Чужой визуальный язык не копируй: графит и тёплая палитра уже есть.

Один главный акцент на экране — одно следующее действие. На «Запуске» это «Запустить», во время работы это «Остановить».

Четыре темы обязательны: режим `auto` / `light` / `dark` и палитра `graphite` / `warm`. Фон не бывает чистым `#000` и чистым `#fff`. Текст на фоне держит контраст 7:1. Приглушённый текст, ссылки, бейджи и подпись на акцентной кнопке держат 4.5:1. Это порог продукта, он строже WCAG AA для основного текста.

Сетка: шаг 8 px, карточка с полями 16 px и зазором 24 px, радиусы 12 / 16 / 20. На ширине 880 px экран не скроллится по горизонтали. На 1440 px поле задачи не растягивается в строку романа.

Шрифт интерфейса — Inter, код, пути и id моделей — JetBrains Mono. Оба покрывают кириллицу. Латинский модный шрифт без кириллицы не подключай.

Доступность: WCAG 2.2 AA. Видимый фокус 2 px цветом акцента с отступом 2 px. Статус — текст плюс иконка, не только цвет. Кнопка «Остановить» доступна с клавиатуры. Смена шага объявляется через `aria-live="polite"`, ошибка — `assertive`. Цель нажатия не меньше 24 px, у главного действия лучше 32 px.

Клавиатура: Tab в зрительном порядке, Ctrl/Cmd+Enter запускает, «Остановить» с клавиатуры (не вешай на Esc закрытие приложения). Поле с фокусом не прячется под шапкой.

Локализация: каждая строка есть в ru и en. Кнопку верстай по более длинной из двух. Русские подписи не обрезай многоточием. `lang` документа совпадает с языком.

Онбординг первого запуска ведёт к одному примеру и кнопке «Запустить». Путь короче, чем справочник. Пропуск в основное окно есть всегда.

Живой рой рисуется из кадров `start`, `step`, `log`, `error`, `done`. Ошибка шага не заменяет весь экран: после неё всё равно приходит `done`. Несколько `step` подряд без завершения предыдущей роли — одна волна, роли стоят рядом. Пустой `agent_id` у `log` — журнал всего запуска.

## Что считать готовым кадром

История Storybook показывает состояние на фикстурах из контракта, без живого ключа API. Снимок Playwright совпадает с макетом. axe чистый. С клавиатуры можно дойти до главного действия и до «Остановить». Строки есть в обеих локалях. Неизвестный кадр стрима не роняет окно.
