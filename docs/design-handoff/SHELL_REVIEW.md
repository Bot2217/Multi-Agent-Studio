# Оболочка и первый запуск

Реализация находится в ветке `design/shell-onboarding`, поверх основы
`design/foundations`. Превью открывается в Storybook, группа «Улей / Студия».

## Что доступно для ревью

- Оболочка с шестью разделами и состоянием недоступного движка.
- Переключение темы и палитры, русский и английский языки.
- Онбординг с облачным и локальным путями, возвратом и пропуском.
- Форма примера задачи с проверкой текста и папки, Ctrl/Cmd+Enter.
- Демонстрационные состояния запуска, остановки и результата.
- Диалог обновления на Radix с захватом фокуса и закрытием через Escape.
- Компоновка для 1200×800 и 880×640.

Настройки хранятся в состоянии превью. Данные ролей и запуска демонстрационные.
Разделы «Агенты», «Модели», «Локальные модели» и «Файлы» показывают состояние
разработки. Их реализация относится к следующим этапам плана.

## Зависимости для интеграции

Bot2217 должен определить интерфейс Tauri, через который новый фронтенд
получает адрес FastAPI и токен текущей сессии. Сейчас документация описывает
файл api.json. Без такого интерфейса браузерное превью не может
аутентифицироваться у движка.

Также требуются маршруты и принятые схемы для чтения и записи оформления,
языка, ключей, настроек запуска и ролей. Подстановка порта или токена в код
фронтенда в этой реализации отсутствует.

Для онбординга нужны признак доступного ключа без самого секрета и список
установленных локальных моделей. Для установки обновления требуется
интерфейс к существующему механизму Tauri с событиями прогресса и ошибки.

Сохранение ключа и установка Ollama обозначены в превью как ожидающие
подключения. Диалог обновления показывает сообщение о недоступности установки
в превью.

## Проверки

Сборка TypeScript и Vite, сборка Storybook. Playwright проверяет оба режима
тёплой палитры на минимальной ширине для четырёх историй, axe, онбординг,
проверку пустой задачи, клавиатурный запуск и остановку, тему и язык,
перевод фокуса при навигации и закрытие обновления в пределах сессии.

Для финальной приёмки по исходному плану нужны утверждённые фреймы Figma.
