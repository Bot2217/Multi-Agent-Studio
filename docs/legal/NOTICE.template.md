# Шаблон NOTICE

Не копировать в корень репозитория, пока таблица не заполнена по фактической заморозке зависимостей. Как заполнять — в [LICENSES.md](LICENSES.md). Это не юридическая консультация.

Когда сверка сделана, файл в корне называется `NOTICE` (без расширения) или `NOTICE.md`, как решит релиз. В установщике он лежит рядом с LICENSE так, чтобы человек мог открыть его из каталога программы.

```text
Улей / Ulei
Copyright (C) 2026 Bot2217 и участники «Улья»

Ядро программы распространяется на условиях GNU AGPL-3.0 или любой более
поздней версии. Текст лицензии — в файле LICENSE.
Исходный код этой версии: {{ССЫЛКА_НА_ТЕГ}}

Программа использует компоненты третьих лиц. Их лицензии остаются за ними.
Ниже — уведомления, которые эти лицензии просят сохранить.
```

Дальше по одному блоку на компонент. Пустые строки не публиковать.

```text
--- {{ИМЯ}} {{ВЕРСИЯ}} ---
Лицензия: {{MIT | Apache-2.0 | LGPL-2.1 | иное}}
Источник: {{URL}}
Копирайт: {{СТРОКА_ИЗ_ИХ_LICENSE}}

{{КРАТКИЙ ТЕКСТ УВЕДОМЛЕНИЯ ИЗ ИХ ФАЙЛА, НЕ ПЕРЕСКАЗ}}
```

Для LGPL-библиотеки добавить:

```text
Исходный код этой библиотеки: {{URL_И_ТЕГ}}
Пользователь вправе заменить её версией, совместимой с LGPL, в порядке,
который описан в её лицензии. Способ замены в этой сборке: {{КАК_ПЕРЕЛИНКОВАТЬ}}.
```

Для весов, если они реально лежат в установщике:

```text
Файл весов {{ИМЯ_ФАЙЛА}} в этот установщик не входит.
```

либо, если входит:

```text
Файл весов {{ИМЯ_ФАЙЛА}} распространяется отдельно от AGPL,
на условиях {{ЛИЦЕНЗИЯ_ВЕСОВ}}: {{URL_ЛИЦЕНЗИИ}}.
```

Ollama, если бинарник лежит в установщике, получает собственный MIT-блок. Если пользователь скачивает Ollama сам, в NOTICE достаточно одной фразы:

```text
По запросу пользователя программа может скачать Ollama (MIT) и веса моделей.
Эти файлы не являются частью исходного кода «Улья». Лицензию конкретного
тега модели пользователь смотрит до загрузки.
```
